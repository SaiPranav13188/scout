# Scout privacy policy

Scout is a personal job-search tool used only by its owner. It is not offered to anyone else.

- **Gmail access:** read-only (`gmail.readonly`). Scout reads job-alert emails from job sites
  (LinkedIn, Wellfound, Internshala, Instahyre) to list the jobs in them. It never sends, deletes or
  changes email, and it does not read other emails for any other purpose.
- **Storage:** job details from those alerts are stored in the owner's own private database. The Google
  sign-in token is stored encrypted.
- **Sharing:** no data is sold or shared with anyone.
- **Removal:** access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: the repository owner, via GitHub.
